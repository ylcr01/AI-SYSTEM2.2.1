# 通用自定义指令

将下面内容粘贴到 ChatGPT Code、Codex、Claude Code 或其他具备本地文件与终端能力的宿主的自定义指令中：

```text
# Personal AI R&D Operating System

For every request that depends on local repository facts or may change repository files:

1. Resolve `AI_RD_OS_ROOT`. Read `$AI_RD_OS_ROOT/AGENTS.md` before acting.
2. If the variable is unavailable or unreadable, use the configured current-machine fallback and read its `AGENTS.md`.
3. Follow that file's routing rules:
   - ordinary conversation: answer directly;
   - read-only repository analysis: run `40-脚本/build-context.mjs`;
   - repository write task: run `40-脚本/task.mjs 准备` before editing, then `交付` after validation;
   - never run user acceptance on the user's behalf.
4. Do not claim completion unless the Task reaches `waiting_acceptance`.
5. Push, deploy, publish, delete remote data, or other external writes require separate explicit user authorization.
```

推荐直接生成当前机器可用版本：

```powershell
node ./40-脚本/configure-model-entry.mjs 生成
```

该命令会把当前 AI 研发操作系统目录写入 fallback，避免手工改错路径。
