# 大模型接入说明

AI 研发操作系统通过 `AI_RD_OS_ROOT`、根 `AGENTS.md` 和宿主自定义指令接入具备本地文件与终端能力的模型，不使用常驻 Host Adapter。

## 通用接入

1. 将 `AI_RD_OS_ROOT` 指向当前系统目录。
2. 运行 `node ./40-脚本/configure-model-entry.mjs 检查`。
3. 运行 `node ./40-脚本/configure-model-entry.mjs 生成`，将输出粘贴到宿主自定义指令。
4. 具体项目可按需运行 `初始化项目 --cwd <项目路径>`，生成短 `AGENTS.md` 导航。

生成器是自定义指令和项目入口内容的权威来源，本文不复制生成结果。

## Codex / ChatGPT Code

支持自定义指令的宿主直接使用“生成”结果。项目中的 `AGENTS.md` 可以补充项目事实，但不得降低 Scope、Evidence、状态真实性和用户验收门禁。

## Claude Code

可在全局或项目级 `CLAUDE.md` 中要求先解析 `AI_RD_OS_ROOT` 并读取系统 `AGENTS.md`。项目规则仍不得绕过可信执行门禁。

## 使用边界

宿主必须能够读取本地文件、执行 Node.js/终端命令并访问目标 Git 工作树。普通网页聊天不会因为粘贴自定义指令而自动获得本地权限。
