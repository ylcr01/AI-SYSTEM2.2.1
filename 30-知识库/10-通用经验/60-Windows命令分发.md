# Windows 分发批处理命令时，应处理 CMD 二次解析

## 触发现象
命中以下场景时考虑：Windows, cmd, 批处理, 路径空格。

## 根本原因
进程参数进入 CMD 后被再次按命令文本解析。

## 处理方法
优先调用确定的可执行程序；必须使用批处理时按 CMD 规则引用完整命令行。

## 验证要求
含空格与不含空格路径都能执行，工具缺失和解释器错误可区分。

## 适用边界
仅在当前项目事实一致时使用；不得覆盖业务规则或替代模型判断。
