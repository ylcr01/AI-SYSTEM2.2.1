# 通用知识库

中央只保存跨不同底座仍成立的经验。项目经验位于 `<项目>/.ai/30-经验`，底座经验位于 `<底座>/.ai/30-经验`。

所有经验均由模型按当前目标自主选择，不自动进入默认上下文。`active` 表示仍可参考，`observe/retired` 通常只在评估或追溯时读取；使用前仍需用当前项目事实重新验证。

优先沉淀用户明确认可的工程取舍和模型在真实任务中反复判断不好的地方，不大量重复通用常识。记录具体条件、为什么这样选择、参考案例和适用边界；已验证修复与用户偏好分清来源，不要求所有经验变成规则或检查器。

先修正当前代码、已有文档或样板，很多失败无需留下新资料。模型已稳定掌握的补偿性经验可以按证据精简；现有 `active/observe/retired` 仅作资料说明，不要求新记录进入生命周期。

用户没有后续相关追问可暂时接受，后续问题继续处理和记录；明确验收也不关闭后续观察。日常反馈留在当前对话，需要复盘或有复用价值时才在合适的已有资料中留下最小记录，不启动中央账本或后台监控。具体例子见[执行方案](../70-文档/77-模型自主研发执行方案.md)。
