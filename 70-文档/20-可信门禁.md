# 可信门禁

正式进入 `waiting_acceptance` 必须同时满足：

- 项目和 Git Root 有效；
- Scope 在 Git Root 内；
- 用户已有改动未被未授权触及；
- ChangeSet 当前有效；
- Evidence Schema、Payload Hash、Acceptance 和 Covers 有效；
- Required Covers 和 Acceptance 均被证明；
- 无 Blocker 和 Blocking Review Finding；
- 用户/项目显式要求的 Review 已满足；
- handoff-required 任务存在新鲜 Handoff。

用户验收前重新执行上述校验。`accepted` 只能通过用户验收事件产生。
