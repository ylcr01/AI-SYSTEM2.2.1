# 按需 Task 规则

本文不进入普通任务上下文。仅在规格变化、重大业务/架构取舍或用户要求整理经验时读取。

## specImpact

交付前按真实 ChangeSet 声明：

- `none`：实现变化，不改变确认后的业务规则；
- `updated`：业务规则或模块规格发生变化，ChangeSet 必须包含对应规格更新；
- `decision-required`：重大业务或架构取舍，ChangeSet 必须包含 Decision。

```powershell
node "$env:AI_RD_OS_ROOT\40-脚本\task.mjs" 交付 --task-id "<taskId>" `
  --spec-impact updated `
  --spec-impact-reason "新增订单退款状态" `
  --spec-id "BR-ORD-004,TR-ORD-006"
```

项目存在 `.ai/spec-map.json` 时，系统会将 Changed Files 映射到 BR/TR/SC/EX ID，并执行规格一致性检查。

## Experience Candidate

只有用户已经验收通过的 Task 才能生成候选：

```powershell
node "$env:AI_RD_OS_ROOT\40-脚本\task.mjs" 整理经验 --task-id "<accepted-task-id>" `
  --root-cause "<已确认根因>" `
  --action "<以后应采取的动作>" `
  --boundary "<适用边界>" `
  --keyword "<关键词1>,<关键词2>"
```

系统只生成 Markdown 候选并执行精确指纹查重，不自动评分，也不自动升级 Contract、Canonical、Skill、Prompt、模板或中央经验。
