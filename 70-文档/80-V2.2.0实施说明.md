# V2.2.0 实施说明

## 架构定位

```text
支持代码执行的大模型宿主
  ↓ 自定义指令 / AGENTS.md
AI-SYSTEM 可信执行内核
  ↓
项目代码、规格、测试和项目经验
```

V2.2.0 没有增加常驻中间服务。入口层仅负责让模型正确识别普通对话、只读分析、仓库写任务和外部写入；可信状态仍由 Task 内核负责。

## 四项新增能力

1. 大模型指令接入：生成可粘贴指令，检查系统入口，按需初始化项目入口。
2. 规格一致性：阻断明确自相矛盾，其他缺口默认告警。
3. Changed File 到规格 ID：以项目显式映射和源码内显式 ID 为事实来源，不按文件名猜测业务。
4. Experience Candidate：已验收来源、透明评分、项目内去重，仍需用户决定是否形成正式经验。

## 轻量化边界

- `.ai/spec-map.json` 和模块规格都可选。
- 未配置映射时，正常 Task 闭环仍可运行。
- 没有规格资产的普通 Bug 修复可声明 `specImpact=none`。
- 默认不因未映射代码或测试追踪缺口阻断交付。
- 只有 `none` 与实际规格变化矛盾、`updated` 未改规格、`decision-required` 无 Decision 等明确矛盾才阻断。
