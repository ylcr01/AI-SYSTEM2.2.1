# 项目质量清单示例

`.ai/quality.json`：

```json
{
  "schemaVersion": 1,
  "contracts": [
    {
      "id": "project-web",
      "version": 1,
      "status": "active",
      "profiles": ["develop-web"],
      "roles": ["web"],
      "artifactKinds": ["code", "ui"],
      "path": "docs/architecture/web-contract.md"
    }
  ],
  "exemplars": [
    {
      "id": "project-customer-feature",
      "status": "active",
      "profiles": ["develop-web"],
      "artifactKinds": ["code", "ui"],
      "structureImpacts": ["structural"],
      "keywords": ["客户", "管理页面"],
      "read": ["src/views/customer", "src/api/customer"],
      "contract": {"id": "project-web", "version": 1},
      "supersededBy": null
    }
  ],
  "disabledDefaults": [],
  "exceptions": []
}
```

`profiles` 是质量路由条件，不是宿主 Skill。读取旧项目清单时仍兼容 `skills` 字段，但新配置统一使用 `profiles`。
