# V2.2.1 修复说明

V2.2.1 是基于 V2.2.0 的可信边界修复版本，不增加常驻服务或自动 Agent 编排。

## 修复范围

1. Evidence 类型和来源使用封闭枚举。
2. Artifact 限定允许根目录并绑定 SHA-256。
3. Check Planner 按 Acceptance ID 与 Cover 规划。
4. spec-map 的规格、测试、Decision Glob 确定性展开。
5. spec-map 配置和读取路径禁止越出 Git Root。
6. Decision Front Matter 校验状态、影响范围和来源 Task。
7. Markdown 正式经验参与解析和去重。
8. 低质量 Experience Candidate 默认拒绝落盘。
9. 规格编排从 Task Runner 拆分为独立服务层。

## 兼容说明

- Task Schema 仍为 V6，V2.2.0 活动任务可直接读取。
- Evidence Schema 仍为 V4，但校验更严格：含 Artifact 的旧 Evidence 若没有 `artifactSha256`，必须重新生成。
- `.ai/spec-map.json` Schema 仍为 V1；过去可逃逸仓库的路径现在会明确报错。
- `.ai/spec-policy.json` Schema 仍为 V1，建议在 `blockingRules` 中加入 `DECISION_METADATA_INVALID`。
- 经验候选 Schema 仍为 V2；评分为 `insufficient` 时默认不保存。
