# V2.1.2 → V2.2.0 升级说明

## 兼容性

- V3/V4/V5 活动 Task 在读取或首次更新时迁移到 Task Schema V6。
- 原有准备、交付、审查、保存、恢复、交接、验收命令保持兼容。
- 原有项目没有 `.ai/spec-map.json` 时，不影响正常任务运行。

## 推荐升级步骤

1. 替换 AI-SYSTEM 目录并设置 `AI_RD_OS_ROOT`。
2. 运行 `node 40-脚本/configure-model-entry.mjs 检查`。
3. 运行 `生成`，将输出放入模型宿主的自定义指令。
4. 长期项目按需复制 `.ai/templates/spec-map.example.json` 为 `.ai/spec-map.json`。
5. 不建议一次性为所有项目创建模块规格；业务规则变化时再最小初始化。

## 行为变化

- `整理经验` 现在必须读取已验收历史 Task，未验收任务会被拒绝。
- `specImpact=updated` 但没有规格文件变化会进入 `needs_rework`。
- `specImpact=decision-required` 但没有 Decision 文件变化会进入 `needs_rework`。
- 交付 Review Package 现在包含稳定的规格追踪和一致性摘要。
