# Documentation Contract

## 强制边界
- 只描述当前可执行事实；历史方案单独归档。
- 结论优先，权威范围明确，不建立第二事实源。
- 命令、路径、版本、链接、输入和输出可验证。
- 文档与代码、配置和当前环境一致。
- 不用冗长背景掩盖决定、限制和残留问题。

## 默认结构
目标读者 → 当前结论 → 适用范围 → 操作/接口 → 边界和失败 → 验证 → 历史或参考。

## 更新
公共接口、配置和运行方式变化时同步更新权威文档；局部内部实现不要求扩大文档范围。
