# 系统集成 Contract

## 工程关注
- 冻结上下游契约、版本、身份、权限和兼容策略。
- 外部 DTO、错误、超时和重试语义留在 Adapter，不泄漏到业务层。
- 明确幂等键、顺序、重复请求、降级和故障归属。
- 并行写入时根据实际 Git 状态选择安全隔离方式，并如实区分各仓库的改动与验证结果。
- 局部成功不能包装成整体成功。

## 联调
契约样例 → 单端适配 → 失败分支 → 真实环境 → 端到端验收。契约变化后应重新判断旧验证结果是否仍然适用。

## 验证
覆盖契约样例、允许/拒绝、超时、重试、重复请求、错误映射、可观测性和目标环境。
