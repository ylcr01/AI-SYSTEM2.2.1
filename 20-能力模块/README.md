# 可选工程资料

本目录中的 Contract 与样板是普通参考资料。模型根据当前用户目标和项目事实自主决定是否读取；本目录不提供中央 Manifest、关键词路由或自动加载。

项目事实高于中央参考。除根入口规定的不可退化边界外，Contract 中的结构、检查和验证内容都是模型可选的工程关注点，不得建立 Task、Scope、Evidence、自动检查或集成生命周期。

## 能力索引

| 目标 | 资料 |
|---|---|
| 澄清真正影响结果的需求歧义 | `clarify-requirements/CONTRACT.md` |
| 设计产品、界面与交互 | `design-product/CONTRACT.md`、`design-ui/CONTRACT.md` |
| 开发 Web、App 或服务端能力 | `develop-web/CONTRACT.md`、`develop-app/CONTRACT.md`、`develop-server/CONTRACT.md` |
| 系统联调与环境操作 | `integrate-systems/CONTRACT.md`、`operate-environments/CONTRACT.md` |
| 文档与经验维护 | `write-documentation/CONTRACT.md`、`curate-knowledge/CONTRACT.md` |

中央 Contract 只保存跨项目仍成立的职责和质量原则。具体框架、目录、文件名和代码写法优先读取目标项目 `AGENTS.md`、附近代码及其已绑定工程模板中的真实样板；没有可用项目样板时，才参考本目录的通用样板。
