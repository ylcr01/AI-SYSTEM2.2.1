# 标准 Web 垂直切片

```text
feature/
├─ index.vue          页面入口与组装
├─ use-case.ts        业务流程和副作用（需要时）
├─ api.ts             远端契约
├─ model.ts           稳定类型与纯转换
├─ components/        具有独立输入输出的组件（需要时）
└─ feature.test.ts    直接保护行为的测试
```

未出现的责任不创建文件。小功能可以只保留 `index.vue + api.ts`。

数据流：路由/用户输入 → 页面入口 → use-case → API → 明确结果/错误 → 页面状态。

至少验证：打开、查询/主操作、成功、失败、权限、重复操作和状态恢复。
